<div className="pok-band">
  <div className="pok-label">01 // The engine</div>

  <h2>Four filters, no opinions</h2>

  <p>Every day PokPok pulls the top 100 Amazon Movers & Shakers in the Beauty category. Each product in that rolling top 100 gets a **POKPOK Index score from 0 to 100**, built from four filters.</p>

  | Filter | What it reads |
  |---|---|
  | **Kinetic Speed** | How quickly the move happened: a slow glide or a sprint through the ranks. |
  | **Stability Filter** | Real momentum versus one-off spikes. Smooth, repeatable climbs score higher; promo-driven sawtooth jumps are cut down. |
  | **Trajectory Gain** | How far the product travelled: start rank versus current rank, tracked day by day. |
  | **Rank Gravity Bonus** | How hard the finish line was. Gains near #1 lift the score far more than the same movement at the bottom. |

  <Note>
    The POKPOK Index is momentum math on Amazon ranks. It does not use the 17 brand perception markers.
  </Note>
</div>

<div className="pok-band pok-band--pink">
  <div className="pok-label">02 // Reading the score</div>

  <h2>What a product's POKPOK Index score means</h2>

  <p>The score runs from 0 to 100. Higher means stronger, cleaner momentum. Each band has its own label.</p>

  | Score | Label | What it means |
  |---|---|---|
  | 90–100 | UNSTOPPABLE FORCE | All filters at maximum. Rare. |
  | 80–89 | ORGANIC CLIMBER | Strong, honest growth. |
  | 70–79 | STEADY THRUST | Solid momentum. |
  | 60–69 | MIXED SIGNALS | Some filters weak. Investigate. |
  | 50–59 | LOSING ALTITUDE | Growth fading or the climb is shaky. |
  | 40–49 | STALLING OUT | Several filters weak. |
  | 30–39 | PROMO DEPENDENT | Growth exists, but it is artificial. |
  | 20–29 | DEAD WEIGHT | No real momentum. |
  | 0–19 | FLATLINE | No movement. |
</div>
