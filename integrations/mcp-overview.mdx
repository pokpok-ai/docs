The Pokpok MCP (Model Context Protocol) integration lets you query Pokpok's brand perception database directly inside Claude — asking natural-language questions about brand markers, saturation scores, and category intelligence. Instead of exporting data and building spreadsheets, you can ask Claude questions and get structured answers drawn from Pokpok's live brand perception database.

## What Is MCP?

MCP is Anthropic's open standard for giving AI assistants access to external data sources. It works like a secure bridge between Claude and an external service — Claude can call tools exposed by the MCP server, retrieve data, and reason over it in the same conversation. The Pokpok MCP server exposes brand perception data to Claude as a set of read-only tools, so Claude can query the database on your behalf without you ever leaving the chat interface.

## Available MCP Tools

| Tool | What It Does |
|---|---|
| `pokpok_about` | Explains the POKPOK AI Score and data model — a good starting point to understand what data is available |
| `pokpok_list_tables` | Lists all available brand perception data tables and their columns |
| `pokpok_query` | Runs a read-only query against Pokpok's brand perception database and returns results |

## Safety and Limits

The Pokpok MCP server is read-only. You cannot write, update, or delete any data through the integration. Each query is subject to a **1,000 row maximum** and a **5-second timeout** — ask Claude to focus your question on a specific category or set of brands to keep results fast and readable.

<Note>
  **Pilot feature.** The Pokpok MCP is currently free with no authentication required. Future versions will require a Pokpok subscription and will authenticate via OAuth 2.1.
</Note>
